# 기존 원판 모델의 빈 출력을 CutMix로 보완한 결과

기존 Mac 베이스라인이 a03의 실제 가림에서 놓친 박스를 CutMix가 찾아냈다. 반대로 b02에서는 기존 모델이 맞힌 프레임을 CutMix가 놓쳤다. 두 모델의 프레임별 출력에 다음 규칙을 적용했다. 기존 모델에 박스가 있으면 그대로 사용하고, 박스가 비어 있을 때만 CutMix의 출력을 확인한다. 선택 과정에서 수동 정답, IoU, 선수 ID 또는 동작 시점은 사용하지 않았다. 두 모델의 시간 연결은 각각 영상 첫 프레임부터 진행했다.

| 검증 6명의 결과 | 기존 모델 | 빈 출력 보완 |
|---|---:|---:|
| 동작 중 270장 직접 검출 미탐 | 16 | 8 |
| 동작 중 270장 시간 연결 후 미탐 | 13 | 5 |
| a03 2–14번 시간 연결 후 최장 연속 미탐 | 13 | 3 |

시간 연결 후 새로 맞힌 8장(4·5·6·10·11·12·13·14번)은 모두 a03 한 시도의 가림 구간이다. 기존 정탐을 잃은 프레임은 0장이었다. 전체 687장 중 보조 모델의 박스를 쓴 프레임은 10장이다. 나머지 2장은 b02의 마지막 수동 이벤트 이후에 있었다. 100번은 IoU 0.487로 매칭에 실패했고 103번은 0.657로 매칭됐다. 동작 중과 같은 가중치로 세지 않았다.

## 원판 없는 학습 배경의 오탐

| 모델 | b05 시간 연결 후 오탐 / 82장 | b06 직접 오탐 / 94장 | b06 시간 연결 후 오탐 / 94장 | b06 최장 연속 오탐 |
|---|---:|---:|---:|---:|
| 기존 Mac 베이스라인 | 0 | 75 | 84 | 42 |
| 3090 대조군 | 0 | 0 | 0 | 0 |
| 3090 CutMix | 0 | 0 | 0 | 0 |
| 기존 우선, 빈 출력 보완 | 0 | 75 | 84 | 42 |

b06 0번에서 기존 모델이 화면 왼쪽 위 천장 가장자리에 신뢰도 0.2503의 박스를 낸 것을 원본으로 확인했다. 기존 박스를 우선하므로 보완 모델도 이 오탐을 그대로 출력한다. 앞선 일지의 두 배경 오탐 0/176은 선수별 3-fold 95에폭 가중치에서 나온 결과였다. 이번에 확인한 두 3090 모델 모두 b06 오탐이 0장이어서 이 차이를 CutMix의 효과로 단정할 수 없다. b05·b06은 두 3090 모델과 기존 모델의 학습에 쓰였다.

보완 규칙은 가림에서 궤적을 이어 볼 실험 후보로 보존한다. 배포용 가중치는 교체하지 않았다. 새 선수의 가림과 원판 없는 독립 배경, 두 모델을 함께 실행할 때의 영상 처리 시간이 채택 판단에 남는다. 지금까지 같은 배경 오탐이 반복된 영상은 b06 한 편이어서 여러 배경에 대한 MixUp 학습의 조건은 충족되지 않았다.
