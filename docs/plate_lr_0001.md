# 73. 원판 검출의 초기 학습률 0.0001 비교

초기 학습률을 0.0005에서 0.0001로 낮추자 선형과 코사인 모두 동작 중 미탐·오탐과 허브 상승량 오차가 커졌다. 검출 후보로 0.0005 코사인을 유지한다. 같은 코사인에서 미탐은 15→40장, 오탐은 0→15장, 좌표 누락은 15→26장, 상승량 평균 절대오차는 2.47→6.62px였다. 새로 찾은 장면은 a03 27번 한 장이고 기존 정탐 26장을 잃었다. 선형에서는 기존 정탐 32장을 잃고 새로 찾은 장면은 없었다.

두 새 모델의 좌표 누락은 전부 a03에서 발생했다. 코사인은 선형보다 a03의 누락을 47→26장, 최장 연속 누락을 17→12프레임으로 줄였다. b02에서는 두 모델 모두 동작 중 17프레임 전체에 좌표를 냈지만, 수동 박스와 IoU 0.50 이상으로 맞은 프레임은 선형 2장, 코사인 3장이었다. b02 접촉 36번에서 두 모델은 밝은 안쪽 원판에 작은 박스를 그렸다. 신뢰도는 각각 0.832·0.855였고 바깥 원판 박스와의 IoU는 0.384·0.393이었다. 무릎 통과→접촉 수동 상승량 326px를 352.83px·355.34px로 과대 측정했다.

같은 0.0001 코사인도 c04의 상승량 오차는 +0.33px로 작았다. 이처럼 선수별 차이가 있고, 이번 추가 실험은 시드 하나와 고정한 학습 일정 안에서 비교했다. 다음 포트폴리오 기록에는 b02의 신뢰도·원본 박스·수동 허브를 함께 써서 좌표가 이어져도 상승량은 틀릴 수 있는 장면을 제시한다.

## 실험 조건

기존 학습 선수 8명 45장과 검증 선수 6명 39장, 원본 YOLO26n, AdamW, 입력 640, 배치 16, 시드 0, 최대 200에폭, patience 30, lrf 0.01과 증강을 유지했다. 두 새 조건은 각각 원본 가중치에서 시작했다. RunPod Community의 NVIDIA GeForce RTX 3090, 570.124.04, 24576 MiB 한 대에서 선형·코사인을 순서대로 학습했다. 이전 0.0005 두 조건의 환경은 NVIDIA GeForce RTX 3090, 580.65.06, 24576 MiB였다. PyTorch 2.8.0+cu128와 Ultralytics 8.4.202를 사용했고 이번 두 학습과 최종 검증 실측 합은 209.71초였다.

Mac CPU에서 일곱 가중치로 검증 6편 687프레임을 각각 처음부터 다시 읽고 같은 시간 연결 규칙을 적용했다. mAP는 고정 검증 사진 39장에서 구했다. 동작 중 수동 박스가 있는 270장에서 IoU 0.50 미만인 선택 박스를 오탐과 미탐에 각각 한 건으로 셌다. 출력이 비면 미탐으로 셌다. 좌표 누락은 동작 중 전체 478프레임을 대상으로 했다. 상승량은 무릎 통과에서 바와 몸이 접촉할 때까지의 세로 이동량이며, 일곱 모델에서 공통 측정이 가능했던 6명의 수동 허브와 비교했다.
