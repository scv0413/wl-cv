# 원판 검출 65·95에폭 비교를 위한 선수별 3-fold 분할

대상은 최초 베이스라인 학습에 실제로 사용한 8명·8편·45장이다. 선수 전체 명단에서 학습으로 지정됐어도 이 데이터셋에 라벨이 없는 영상은 제외했다. 기존 검증 6명(a03, a05, b02, b03, c04, c08)의 39장은 세 fold 모두에서 학습·내부 검증에 사용하지 않는다.

[선수별 분할표](../data/splits/plate_person_3fold.csv)의 `heldout_fold`는 그 선수를 검증하는 회차다. 해당 번호의 선수를 통째로 빼고 나머지 행의 선수로 학습한다. 프레임 번호는 원본의 첫 장을 0으로 센다. 양성 선수 두 명씩을 서로 다른 A/B/C 그룹에서 짝지었고, 반 동작인 a06의 4장과 두 배경 영상의 3장씩을 고려해 내부 검증 크기를 14~17장으로 맞췄다.

| 회차 | 내부 검증 원판 있음 (장) | 내부 검증 원판 없음 (장) | 내부 검증 합계 | 나머지 학습 선수 | 학습 원판 있음 / 없음 | 직접 확인 / 판독 불가 |
| --- | --- | --- | ---: | --- | ---: | ---: |
| 1 | a06 (4), c02 (7) | b05 (3) | 14 | a01, b01, b04, b06, c05 | 28 / 3 | 11 / 0 |
| 2 | b04 (7), c05 (7) | b06 (3) | 17 | a01, a06, b01, b05, c02 | 25 / 3 | 14 / 0 |
| 3 | a01 (7), b01 (7) | 없음 | 14 | a06, b04, b05, b06, c02, c05 | 25 / 6 | 14 / 0 |

## 65·95에폭에서 비교할 수 있는 지표

| 질문 | 채점할 수 있는 장면과 기준 |
| --- | --- |
| 원판을 어느 에폭이 더 자주 잡는가? | 원판 박스가 있는 39장(회차별 11·14·14장). 각 회차에서 원본 사전학습 가중치로 한 번 학습한 뒤 같은 실행의 65·95에폭을 채점한다. 기존 직접 검출 방식(신뢰도 0.10 이상에서 가장 높은 후보, IoU 0.50 이상)을 고정하고 선수별 정탐·미탐 수, 95에서 복구·손실한 프레임 번호를 짝지어 보고한다. 박스 IoU는 두 모델이 모두 맞힌 프레임 수와 함께 제시한다. |
| 실제 동작 중에도 차이가 있는가? | 기존 1차 판독의 ready~finish 구간(하프는 마지막 판독 이벤트까지)에 들어가는 양성 라벨은 11·7·14장, 총 32장이다. c05는 finish만 있어 7장을 전체 박스 평가에만 넣는다. 시간 연결을 비교할 경우 각 영상을 처음부터 연속 추론한 뒤 라벨 프레임에서만 채점한다. 양성 라벨 간격이 벌어져 있어 이 45장만으로 연속 미탐 길이를 정할 수 없다. |
| 원판이 없는데 잡는가? | 회차 1은 b05, 회차 2는 b06의 빈 라벨 각 3장에서 오탐 프레임 수 / 3을 비교할 수 있다. 프로젝트에서 영상 전체에 대상 원판이 없음을 확인한 두 원본도 각각 82·94프레임까지 읽혔다. 해당 선수를 학습에서 제외한 회차에서 각각 영상 전체 오탐 프레임 비율과 최장 연속 오탐 길이(프레임)를 추가로 채점할 수 있다. 회차 3의 배경 전용 오탐률은 분모가 없어 미측정이다. |
| 허브 높이를 더 정확히 잡는가? | 직접 확인한 39장에서 두 에폭이 모두 정탐한 프레임을 짝지어 센다. 각 에폭에서 예측 박스 중심 y와 수동 허브 y의 평균 절대 오차 및 부호 있는 평균 편향을 원본 px로 보고한다. 양수는 예측이 수동점보다 아래다. |

## 집계 근거

- 기존 분할표와 베이스라인의 `train_people.csv`를 대조하고 학습·검증 이미지와 YOLO 라벨 파일명이 각각 일치하는지 확인했다. 각 학습 선수는 한 회차에서만 검증 대상이며, 각 회차의 학습·내부 검증 선수는 겹치지 않는다. 45장 중 39장에 원판 박스가 1개씩 있고 6장은 빈 라벨이다.
- 이벤트는 `data/annotations/point_labels.csv`의 1차 판독을 사용했다. a06은 ready 2번부터 drive 27번까지다. CSV의 `motion_positive_frames` 빈칸은 시작점을 판정할 수 없는 c05이고, 배경 선수의 0은 양성 라벨이 없다는 뜻이다.
- 분할표 작성 당시의 직접 허브는 `temporal_plate_centers.csv`, `additional_temporal_review.csv`, `hub_review/`, `hub_rise_repeat/`, `plate_blur_review/validation.csv`에서 직접 판독 상태와 유효한 x·y가 있는 영상·프레임만 세었다. 동일 프레임의 재판독은 한 장으로 센다. 박스 중심, 관절 수동점, 대략 추정한 허브는 집계에서 제외했다.
- 회차별 평가 결과를 합칠 때는 각 선수의 내부 검증 예측만 한 번씩 사용한다. 같은 회차의 검증 점수로 고른 최고 에폭 대신 미리 지정한 65·95에폭을 비교한다. 이 표는 학습 전 데이터 집계이며 검출 성능 수치는 아직 없다.

## 2026-11-25 허브 판독 완료 및 실행 방법

양성 프레임 39장의 직접 확인 좌표는 모두 원본 영상 범위 안에 있다. 판독 불가와 미판독은 각각 0장이다. 분할표의 `direct_hub_frames`는 새 판독 이전 집계이고, 현재 집계는 `data/annotations/plate_fold_hubs/`의 좌표를 읽는다.

[3-fold 학습 및 비교 노트북](../notebooks/experiments/43_plate_3fold_epoch65_95.ipynb)에서 분할 확인 → 학습 → 평가 순서로 실행한다. 학습 선수 범위 안에서 각 선수가 한 번씩 검증 대상이다. 학습 완료 후 각 실행의 `weights/`에서 `epoch_65.pt`, `epoch_95.pt`, `best.pt`, `last.pt`를 확인하고 결과는 로컬 `outputs/plate_3fold/`에 저장한다.

## 선수별 3-fold 학습 결과 · 2026-11-25

각 회차에서 YOLO26n을 Mac MPS로 100에폭 학습했다. 매번 같은 사전학습 가중치와 베이스라인 학습 일정을 사용했다. 8명은 각자 한 회차에서만 내부 검증에 들어갔다. 학습 선수와 해당 회차의 검증 선수는 겹치지 않았다. 각 실행의 1~100에폭 로그, 65·95에폭 체크포인트 내부 번호와 데이터 경로, `best.pt`와 `last.pt`를 확인했다.

| 내부 검증 | 양성 라벨 | 미탐 65 → 95 | 수동 허브 세로 평균 절대 오차 65 → 95 | 박스 mAP50–95 65 → 95 |
| --- | ---: | ---: | ---: | ---: |
| Fold 1 · a06, c02 (+ 배경 b05) | 11장 | 0 → 0 | 3.95 → 2.29 px | 0.94476 → 0.97035 |
| Fold 2 · b04, c05 (+ 배경 b06) | 14장 | 0 → 0 | 2.81 → 4.06 px | 0.94711 → 0.94537 |
| Fold 3 · a01, b01 | 14장 | 0 → 0 | 2.35 → 3.31 px | 0.95633 → 0.97510 |
| 전체 양성 | 39장 | 0 → 0 | 2.97 → 3.29 px | — |
| 동작 구간이 확인된 양성 | 32장 | 0 → 0 | 2.92 → 3.05 px | — |

직접 검출은 신뢰도 0.10 이상, 정탐은 정답 박스와 IoU 0.50 이상으로 정했다. 양성 39장은 모두 두 에폭의 직접 검출로 정탐이었다. 95에폭에서 새로 복구하거나 잃은 라벨 프레임은 각각 0장이다. 드문 시점에 붙인 라벨이므로 양성 영상의 라벨 사이 구간에는 미탐이 있을 수 있다. c05는 동작 시작 기록이 없어 7장 모두 전체 비교에만 포함했다.

**배경 영상에서 차이가 드러났다.** b05 82프레임의 오탐은 두 에폭 모두 0장이었다. b06 94프레임을 다시 추론하니 65에폭이 73~80번에서 8장 연속 오탐했다(8.5%). 시간 연결은 81·82번의 저신뢰 후보까지 이어 10장 연속 오탐했다(10.6%). 78번의 예측 상자(신뢰도 0.189)는 선수 오른편 벽의 글자와 매달린 줄이 함께 보이는 구역을 덮었다. 95에폭은 직접 검출과 시간 연결 모두 0/94장이었다. b06의 빈 라벨 세 장(11·31·64번)만 평가하면 두 에폭 모두 오탐 0장으로 기록된다. Fold 3에는 배경 전용 영상이 없다.

**박스와 허브는 다른 질문에 답한다.** Fold 3은 95에폭에서 박스 mAP50–95가 올랐지만 허브 세로 오차도 커졌다. b04 21번은 정답 박스와 IoU가 0.966 → 0.969로 비슷했는데 예측 중심은 직접 찍은 허브보다 7.78 → 9.57 px 위에 있었다. 전체 39장에서 수직 편향(예측 중심 y − 수동 허브 y)은 −1.36 → −2.03 px였다. 동작 중 평균 절대 오차 차이 0.13 px는 선수·회차별로 방향이 달랐고 수동 판독의 반복 오차와도 아직 대조하지 않았다.

**결정.** 운영용 원판 검출기는 전체 학습 선수 8명으로 만든 기존 베이스라인 `best.pt`를 유지한다. 이전 고정 검증 6명의 동작 중 270장에서 95에폭은 직접 미탐을 25 → 16장으로 줄였고, 이번 내부 검증에서는 b06의 연속 오탐이 사라졌다. 이번 세 회차의 모델은 각자 일부 선수를 빼고 학습한 비교용 가중치다. 이번 실험은 같은 100에폭 일정의 두 중간 시점을 비교했으므로 `patience=20`의 효과나 최적 에폭은 정할 수 없다. 다음에는 기존 검출기를 고정하고, 이륙·무릎 통과처럼 양 끝의 허브를 직접 찍은 구간에서 **예측 상승량과 수동 상승량의 차이**를 먼저 확인한다. 두 시점에서 중심이 비슷하게 치우치면 상승량에서는 그 오차가 상쇄될 수 있다.
