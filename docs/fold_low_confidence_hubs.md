# 95에폭 모델로 학습에서 제외한 선수의 원본 허브 판독 대상 찾기

선수별 3-fold의 95에폭 모델로 각 회차에서 학습에 쓰지 않은 선수의 원본을 확인했다. 기존 수동 이벤트로 동작 구간을 확정한 407장 모두 직접 검출이었다. 수동 박스와 대조한 47장에서는 IoU 0.50 미만이 없었다. 시간 연결·출력 누락·확인된 위치 미매칭을 같은 구간의 고신뢰 대조와 묶는 조건을 충족한 짝은 0쌍이다.

| Fold | 학습에서 제외한 선수 | 동작 구간을 확인한 원판 영상 | 동작 중 직접 검출 | 수동 박스와 매칭 |
|---|---|---|---:|---:|
| 1 | a06, b05, c02 | a06, c02 | 120/120 | 12/12 |
| 2 | b04, b06, c05 | b04 | 91/91 | 10/10 |
| 3 | a01, b01 | a01, b01 | 196/196 | 25/25 |

- 학습 선수 8명의 원본 18편, 2,007장을 영상별로 처음부터 끝까지 재생했다. fold별 분할표, 실제 학습 명단, 가중치 내부 에폭·학습 데이터 경로를 확인했다. 추가 시도가 있는 선수의 영상도 같은 fold에서만 실행했다. 운영 베이스라인을 고르는 데 사용한 고정 검증 6명은 포함하지 않았다.
- Mac MPS에서 입력 640, 후보 하한 0.001, 직접 검출 기준 0.10, 시간 연결 반경 0.5배를 사용했다. 확인된 동작 구간은 전체 동작의 ready~finish, 하프 동작의 ready~drive 양 끝을 포함한다. 407장 중 최저 직접 신뢰도는 0.914였고, 원본·참조 박스가 있는 47장의 최저 IoU는 0.741이었다. 나머지 동작 중 360장은 수동 박스가 없어 정확한 대상과의 위치 매칭을 채점하지 않았다.
- 수동 시점이 불완전한 11편 1,298장, 확인된 동작 구간 바깥 126장은 별도로 집계했다. 두 범위 모두 선택 결과가 직접 검출이었다. 원판이 없는 b05·b06은 176장 전체에서 출력이 없었으며 배경 오탐은 0장이었다.
- 같은 영상의 같은 수동 동작 구간에서 앞뒤 5장 이내, 직접 신뢰도 0.50 이상의 대조를 한 번씩만 사용하도록 설계했다. 정답 박스가 있는 대조는 IoU 0.50 통과도 요구한다. 이 표본에서는 후보 자체가 없어 저신뢰와 고신뢰 사이의 허브 오차 차이를 계산할 수 없었다. 허브 보정 학습을 시작할 근거는 추가되지 않았다.

[18번 판독 노트북](../notebooks/annotation/18_fold_low_confidence_hubs.ipynb)의 기본 모드는 이번 짝을 읽는다. 선택 검수 모드는 선수별 무릎 통과~접촉 사이에 있는 새 원본 1장씩, 총 5장을 열어 직접 허브를 찍을 수 있게 한다. 이미 판독한 39장은 제외했으며 새 장면을 고를 때 점수와 모델 오차를 사용하지 않았다. 원본을 누르면 저장하고, 가려져 있으면 판독 불가로 남긴다. 모든 판독이 끝나야 예측을 열 수 있다. 두 모드의 수동점은 서로 다른 폴더에 저장한다.

모델을 다시 실행할 때는 프로젝트 폴더에서 `.venv/bin/python -m wlcv.evaluation.fold_hub_screen`을 실행한 뒤 노트북 첫 셀부터 연다. 전체 프레임 기록과 모델 해시는 로컬 `outputs/fold_hub_screen/`, 수동점은 `data/annotations/fold_low_confidence_hubs/` 아래 실행별로 저장한다.
