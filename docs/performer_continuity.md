# 직전 수행자 박스로 동작 중 다인 후보 연결

원본 YOLO26n-pose를 Mac MPS에서 입력 640, 배치 1로 실행했다. 동작 중 다인 후보 11장에서 기존 단일 후보 방식은 모두 보류했다. 직전 프레임 선택 박스와 IoU 0.50 이상인 후보가 하나일 때 연결하면 6장 정선택, 0장 오선택, 5장 보류였다. 출력 누락 뒤에는 이전 박스를 지우고 단일 후보에서 다시 시작했다. 후보가 여러 개여도 같은 수행자의 일부와 전신이 중복 검출될 수 있다.

| 영상 | 동작 중 장수 | 후보가 여럿인 장수 | 올바른 복구 / 오선택 / 보류 | 체간 각도 출력 · 기존 → 실험 |
|---|---:|---:|---:|---:|
| b02 (주 비교) | 17 | 5 | 4 / 0 / 1 | 12 → 16 |
| c04 (단일 후보 대조) | 97 | 0 | — | 97 → 97 |
| a03 | 103 | 1 | 0 / 0 / 1 | 95 → 95 |
| a05 | 68 | 2 | 2 / 0 / 0 | 66 → 68 |
| b03 | 106 | 1 | 0 / 0 / 1 | 105 → 105 |
| c08 | 87 | 2 | 0 / 0 / 2 | 85 → 85 |

- 원본 영상 여섯 편 687장을 각각 첫 프레임부터 끝까지 추론했다. 비교하는 두 방식에 매 프레임 같은 자세 후보를 전달했다. b02·c04 232장에서는 52번 실행의 후보 수와 기존 모델 각도(결측 포함)를 재현했다. c04의 동작 중 97장은 선택과 각도가 모두 같았다.
- b02 30~33번이 복구됐다. 34번의 직전 박스와의 IoU는 0.842와 0.633으로 둘 다 기준을 넘어 보류했다. 20번 22.94°와 30번 9.95°에서 이륙→무릎 통과 모델 변화량은 −12.99°였다. 과거에 수행자를 확인해 골랐을 때의 결과가 재현됐다. 트레이너의 소켓 추정점을 포함한 1·2차 판독에서는 변화량이 각각 +5.11°와 +7.60°였다. 이 둘은 직접 확인한 골반을 쓴 각도 정답으로 채점하지 않는다.
- b02 결과를 본 뒤 규칙·임계값을 고정해 나머지 네 영상에서 후속 비교했다. 동작 중 다인 후보 6장을 모두 원본에서 확인했다. a05 22·23번만 추가 복구됐다. b03·c08의 세 장에서는 서로 다른 후보 박스 둘이 같은 수행자 참고 박스와 각각 IoU 0.50 이상이었다.
- 참고 박스는 이 작업에서 예측 박스를 열기 전 원본을 보고 표시한 화면상 외곽이다. 작업 보조자의 시각 판독이며 트레이너가 새로 그린 라벨은 아니다. 유일하게 참고 박스와 매칭된 후보를 선택하면 정선택으로 셌다. 검증 범위는 동작 중 다인 후보가 나온 11장이다. 다른 시점의 단일 후보가 항상 올바른 사람인지는 평가하지 않았다.

TensorRT 비교에는 원판 베이스라인, 원본 자세 모델, 입력 640, 기존 보류 방식을 사용한다. 수행자 연결은 실험 노트북에서만 실행한다. 여러 후보가 같은 수행자 위에 겹친 장면에서 기준을 낮추지 않는다. 코칭에 쓸 체간 방향을 개선하려면 수행자 선택과 별도로 확인 가능한 골반 기준을 확보해야 한다.

## 배포 버전의 전경 수행자 선택

고정 측면 카메라에서 가장 가까운 선수가 분석 대상이다. 한 대의 카메라 영상에서는 박스 크기와 앞뒤 프레임의 위치로 전경을 추정한다.

- 서로 떨어진 사람 후보는 전신 박스 면적을 비교한다. 가장 큰 박스가 다음 박스의 1.25배 이상이면 그 사람을 선택한다. 크기가 비슷하면 직전 선수 박스와 IoU 0.50 이상인 비슷한 크기의 후보가 하나일 때 연결한다.
- 같은 몸에 전신·부분 박스가 겹칠 수 있다. 가장 큰 두 박스가 IoU 0.50 이상 겹치고 직전 관측이 있으면 직전 박스와의 IoU가 0.50 이상이고 차순위보다 0.10 이상 높은 앞쪽 후보를 선택한다. 구분이 어려운 프레임은 자세를 보류한다.
- 다인 장면에서는 선택된 사람 박스 주변의 원판 후보를 남긴 뒤 기존 직접 검출·시간 연결·CutMix 보완을 적용한다. 원판 테두리가 사람 박스의 가로·세로 15% 여유 범위에 닿으면 머리 위나 발 앞에 있는 원판도 추적할 수 있다. 사람을 고르지 못했을 때는 모든 사람 박스가 서로 IoU 0.50 이상 겹치고 원판이 공통 범위에 있을 때만 원판 추적을 허용한다.
- CSV의 `person_candidates`는 사람 후보 수, `performer_number`는 그 프레임에서 선택한 후보 번호(1부터), `performer_selection`은 선택 근거다. `performer_x1/y1/x2/y2`에 해당하는 네 열에는 선택 박스의 원본 좌표를 기록한다. 관절은 선택된 선수의 가까운 쪽에서 신뢰도 0.50 이상인 점만 표시한다.

| 확인 범위 | 결과 |
| --- | --- |
| 개발자 본인 b00, Mac CPU FastAPI 및 CPU Docker, 254프레임 | 네 관절이 표시된 프레임 68→254장. 다인 후보가 나온 186장에서 모두 전경 후보를 선택. 준비 41번·바 접촉 82번·캐치 121번에서 원본과 출력 관절을 대조. 준비→캐치 원판 박스 중심 상승량 +556.2 px 유지. |
| 기존 검증 6명, 동작 중 다인 11장의 원본 판독 박스 | 11장 모두 선택 박스와 판독 박스의 IoU 0.50 이상. b02 34번은 넓은 박스를 우선하면 0.486, 직전 박스를 따라가면 0.744. 중복 후보가 같은 몸에 겹친 경우가 있어 관절 위치의 정확도는 별도 평가 대상. |
| 같은 6명의 동작 중 원판 라벨 270장, 수동 허브 상승량 6구간 | 미탐 5장, 오탐 0장, 허브 상승량 평균 절대오차 2.23 px 유지. |

b00는 학습 분할의 사용 예시다. 검증 11장의 참고 박스는 기존 원본 시각 판독에 기반한다. 두 선수가 동시에 들어 올리거나 화면상 크기가 비슷하게 겹치는 촬영에서 실제 깊이 순서와 원판 소유자를 얼마나 자주 맞히는지는 추가 검증 대상이다.

### 면적 기준과 원판 여유 범위를 한 번에 하나씩 바꾼 결과

[78번 비교 노트북](../notebooks/experiments/78_foreground_thresholds.ipynb). 같은 검증 6편 687프레임에서 사람·원판 모델을 한 번씩 실행하고, 다섯 조건에서 각각 첫 프레임부터 주 모델과 CutMix의 이력을 재생했다. 대조군은 기존 배포 CSV의 프레임별 수행자 선택, 근거, 원판 모델·검출 상태 및 좌표와 일치했다(좌표 허용차 0.001 px).

| 사람 면적 기준 | 원판 여유 | 수행자 선택 변경 (687장) | 원판 후보 목록 변경 (687장) | 최종 원판 변경 (687장) | 동작 중 원판 미탐 / 오탐 (270장) |
| --- | --- | ---: | ---: | ---: | ---: |
| 1.25배 | 15% | 대조군 | 대조군 | 대조군 | 5 / 0 |
| 1.10배 | 15% | 1 | 1 | 0 | 5 / 0 |
| 1.50배 | 15% | 0 | 0 | 0 | 5 / 0 |
| 1.25배 | 0% | 0 | 5 | 0 | 5 / 0 |
| 1.25배 | 10% | 0 | 4 | 0 | 5 / 0 |

- **수행자.** 다인 후보는 전체 19장, 동작 중 11장. 동작 중 다섯 조건 모두 오선택·보류 0장. 11장 중 8장은 판독 박스에 유일하게 일치했고, 3장은 같은 수행자에 후보가 여럿 겹쳐 번호만으로 신원을 구분하기 어려웠다.
- **실제로 바뀐 장면.** b02 103번은 채점 동작(20~36번)이 끝난 뒤다. 사람 후보 두 개의 면적비는 1.244배였다. 1.10배에서는 원판과 바닥에 걸친 넓은 박스로 바뀌었다. 102·104번 원본과 대조하면 수행자는 화면 왼쪽에 서 있다. 1.25·1.50배는 직전 선수 박스와 IoU가 0.853인 왼쪽 후보를 유지했다(하단 후보 0.128). 이 한 장은 기존 수행자 판독 라벨이 없어 앞뒤 원본에 따른 시각 판정이다. 원판은 모든 조건에서 같은 직접 검출, 정답 IoU 0.657.
- **원판.** 여유를 0%로 줄이면 a03 25번과 b02 17·18·31·32번의 후보 목록이 달라졌다. 10%에서는 b02 네 장만 달라졌다. 기준을 통과한 최종 원판과 이후 궤적은 모든 프레임에서 같았다. 원판 정답이 있는 동작 전 20장의 미탐·오탐은 0/0, 동작 후 79장은 18/2로 모든 조건에서 같았다. 라벨이 없는 프레임은 출력 차이만 확인했다.
- **채택.** 현재 1.25배·15% 유지. 1.10배에서 동작 후 수행자 오선택이 1장 늘었다. 1.50배와 여유 0·10%는 개선 근거가 없었다. 15%가 가림이나 머리 위 원판을 추가로 복구한다는 증거도 이번 표본에서는 없었다. 다른 선수가 비슷한 크기로 겹치거나 두 원판이 함께 보이는 새 영상에서 다시 비교할 수 있다.
