# 직전 수행자 박스로 동작 중 다인 후보 연결

원본 YOLO26n-pose를 Mac MPS에서 입력 640, 배치 1로 실행했다. 동작 중 다인 후보 11장에서 기존 단일 후보 방식은 모두 보류했다. 직전 프레임 선택 박스와 IoU 0.50 이상인 후보가 하나일 때 연결하면 6장 정선택, 0장 오선택, 5장 보류였다. 출력 누락 뒤에는 이전 박스를 지우고 단일 후보에서 다시 시작했다. 후보가 여러 개여도 같은 수행자의 일부와 전신이 중복 검출될 수 있다.

| 영상 | 동작 중 장수 | 후보가 여럿인 장수 | 올바른 복구 / 오선택 / 보류 | 체간 각도 출력 · 기존 → 실험 |
|---|---:|---:|---:|---:|
| b02 (주 비교) | 17 | 5 | 4 / 0 / 1 | 12 → 16 |
| c04 (단일 후보 대조) | 97 | 0 | — | 97 → 97 |
| a03 | 103 | 1 | 0 / 0 / 1 | 95 → 95 |
| a05 | 68 | 2 | 2 / 0 / 0 | 66 → 68 |
| b03 | 106 | 1 | 0 / 0 / 1 | 105 → 105 |
| c08 | 87 | 2 | 0 / 0 / 2 | 85 → 85 |

- 원본 영상 여섯 편 687장을 각각 첫 프레임부터 끝까지 추론했다. 비교하는 두 방식에 매 프레임 같은 자세 후보를 전달했다. b02·c04 232장에서는 52번 실행의 후보 수와 기존 모델 각도(결측 포함)를 재현했다. c04의 동작 중 97장은 선택과 각도가 모두 같았다.
- b02 30~33번이 복구됐다. 34번의 직전 박스와의 IoU는 0.842와 0.633으로 둘 다 기준을 넘어 보류했다. 20번 22.94°와 30번 9.95°에서 이륙→무릎 통과 모델 변화량은 −12.99°였다. 과거에 수행자를 확인해 골랐을 때의 결과가 재현됐다. 트레이너의 소켓 추정점을 포함한 1·2차 판독에서는 변화량이 각각 +5.11°와 +7.60°였다. 이 둘은 직접 확인한 골반을 쓴 각도 정답으로 채점하지 않는다.
- b02 결과를 본 뒤 규칙·임계값을 고정해 나머지 네 영상에서 후속 비교했다. 동작 중 다인 후보 6장을 모두 원본에서 확인했다. a05 22·23번만 추가 복구됐다. b03·c08의 세 장에서는 서로 다른 후보 박스 둘이 같은 수행자 참고 박스와 각각 IoU 0.50 이상이었다.
- 참고 박스는 이 작업에서 예측 박스를 열기 전 원본을 보고 표시한 화면상 외곽이다. 작업 보조자의 시각 판독이며 트레이너가 새로 그린 라벨은 아니다. 유일하게 참고 박스와 매칭된 후보를 선택하면 정선택으로 셌다. 검증 범위는 동작 중 다인 후보가 나온 11장이다. 다른 시점의 단일 후보가 항상 올바른 사람인지는 평가하지 않았다.

TensorRT 비교에는 원판 베이스라인, 원본 자세 모델, 입력 640, 기존 보류 방식을 사용한다. 수행자 연결은 실험 노트북에서만 실행한다. 여러 후보가 같은 수행자 위에 겹친 장면에서 기준을 낮추지 않는다. 코칭에 쓸 체간 방향을 개선하려면 수행자 선택과 별도로 확인 가능한 골반 기준을 확보해야 한다.
