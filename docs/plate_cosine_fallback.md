# 코사인 원판 모델의 주·보조 조합 비교

## 실험 조건

코사인 모델이 원판 위치를 내지 못할 때 다른 가중치가 빈 구간을 채울 수 있는지, 코사인을 보조로 쓰면 기존 정탐과 허브 상승량이 어떻게 달라지는지 확인했다. 저장된 가중치 9개 각각에 검증 원본 6편(687프레임)과 학습에서 본 빈 배경 b05·b06(82·94프레임)을 Mac CPU로 재생했다. 각 가중치의 학습 인물 목록과 검증 분할을 확인했다. 입력 640, 시간 연결, 화면 경계 규칙을 고정하고 매 영상 첫 프레임에서 이력을 초기화했다.

각 모델의 이력을 독립적으로 갱신한 후, 선순위 모델에 좌표가 없을 때만 다음 모델의 출력을 사용했다. 선정에는 정답·수동 허브를 쓰지 않는다. 단독 9개, 두 모델 17개, 세 모델 2개로 총 28개 조건이다. 회색·질감 가림, scale 0 및 0.25, hsv_v 0, 기존 3090 학습 일정은 재학습 없이 비교할 수 있는 대표 조건으로 미리 선정했다.

## 평가 기준

동작 중 수동 박스 270장에서 최종 박스 IoU 0.50을 기준으로 미탐·오탐을 세고, ready부터 마지막 확인 시점까지 478프레임에서 좌표가 비는 구간을 셌다. b02는 마지막 시점인 접촉까지 포함한다. 상승량은 무릎 통과와 접촉에서 모델 박스 중심의 세로 이동량을 직접 찍은 허브와 비교했다. ¹복구와 손실은 기존 Mac → CutMix 보조의 동작 중 정탐과 프레임별로 대조한 값이다. b05·b06은 새 촬영 환경의 오탐 평가에 포함하지 않았다.

## 배포 판단과 대표 장면

CutMix를 제외하면 코사인 주 모델에 Mac·질감 가림·scale 0.25·밝기 증강을 끈 모델을 각각 붙인 네 조건이 동작 중 미탐 12장, 오탐 0장, 최장 누락 12프레임, 상승량 평균 절대오차 2.47 px로 같았다. 코사인 단독의 누락 15장 중 3장을 채웠지만 기존 Mac → CutMix의 정탐 265장 중 7장을 놓쳤다. Mac을 주 모델, 코사인을 보조로 바꾸면 미탐은 똑같이 12장이지만 상승량 오차는 6.21 px가 된다. 두 모델 모두 박스를 낼 때 선순위 모델의 좌표를 사용하기 때문이다.

회색 가림 모델을 보조로 쓰면 b02 35번의 수동 허브 세로 오차가 6.05 px였다. 같은 프레임의 Mac 보조 오차는 47.94 px였다. 회색 보조는 동작 미탐 14장이 남았고, 원판이 없는 학습 배경 b05에서 82장 중 12장(최장 9프레임)을 잘못 연결했다. 이 한 프레임의 개선을 배포 모델 교체 근거로 삼기는 어렵다.

코사인 → Mac → CutMix 순서는 기존 정탐 265장 전부를 유지하면서 상승량 오차가 6.21 → 2.47 px로 줄었다. 동작 478장에서 코사인 463장, Mac 3장, CutMix 7장을 선택했고 5장은 좌표가 비었다. 역순인 Mac → CutMix → 코사인에서는 기존 상승량 오차 6.21 px가 유지됐다. 세 모델을 계속 돌리는 추적 방식은 동작 중 신규 정탐이 0장이었고, b02 35번은 Mac 좌표여서 수동 허브보다 47.94 px 아래였다. 이 조합의 순간속도 정확도나 영상 출력까지의 지연은 검증하지 않았다.

### 상승량을 읽을 때만 코사인을 추가하는 비교

두 시점을 제공할 수 있는 영상에서는 코사인을 무릎 통과와 접촉에서만 독립적으로 실행했다. 양쪽 모두 직접 검출(신뢰도 0.10 이상)되고 기존 추적 박스와의 IoU가 각각 0.50 이상일 때만 두 코사인 좌표로 상승량을 계산했다. 한쪽이라도 실패하면 두 시점 모두 기존 추적값을 사용했다. 수동 허브는 선택 후 채점에만 사용했다. 보고서의 상승량 출처를 구분하며, 영상과 프레임별 궤적은 원래 좌표를 표시한다.

검증 6편에서 코사인은 총 12프레임에 추가 추론했다. 11장에서 박스를 확인했고 5명의 상승량을 코사인으로 계산했다. a03 접촉 25번은 시간 연결을 쓸 때 신뢰도 0.097로 검출되는 프레임이어서, 한 장만 보는 직접 검출에서는 보류하고 두 시점 모두 Mac 좌표를 사용했다. Mac 단독 궤적과 Mac → CutMix 궤적 어느 쪽을 써도 6명 평균 절대오차는 6.21 → 2.23 px였다. a03·a05·b02·b03·c04·c08 순으로 오차는 −0.67, +1.94, −1.71, −3.79, −2.57, −2.71 px였다. b02에서 수동 상승량 326 px에 대해 305.80 → 324.29 px가 됐다. 이 수치는 두 시점 사이에서 직접 읽은 허브와 모델 박스 중심의 변위 차이다.

배포 기본 추적은 Mac 단독, 가림 복구 옵션은 Mac → CutMix로 유지한다. 코사인은 수동 시점이 주어지는 보고서의 상승량 보조 후보로 남긴다. 2.47 px와 2.23 px 차이에는 a03 한 사람의 보류가 반영됐다. 반복 평가한 6명에서 설계한 판정이므로 새 선수에 대한 우월성이나 프레임별 속도 개선으로 확대 해석하지 않는다.

Mac CPU에서 원본 6편을 실제 두 모델 추적기로 다시 실행해 코사인 → Mac과 기존 Mac → CutMix 각각 687장의 박스·중심·신뢰도·선택 출처가 조합표와 일치함을 확인했다. 영상 디코딩과 원판 추적에 걸린 벽시계 시간은 1회씩 53.47초와 54.95초였다. 자세 추론과 오버레이 저장은 이 측정에서 제외했다.
