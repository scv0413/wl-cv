# 궤적을 이어가는 원판의 화면 경계 예외

기존 경계 필터는 b06의 천장 오탐을 지웠지만 b02 77·78번에서 화면 위로 잘린 실제 원판도 제외했다. 경계 1px 이내이며 너비가 높이의 3배 이상인 후보로 새 궤적을 시작하는 것은 막고, 직전 관측으로 예상한 중심에서 직전 박스 너비의 0.5배 반지름 안에 있으면 허용했다. 마지막 고신뢰 관측이 2프레임을 넘으면 이 예외를 적용하지 않았다.

65번에서 저장한 Mac CPU 입력 640의 두 모델 후보를 사용했다. 각 모델·영상·조건의 이력을 비우고 0번부터 8편 863프레임을 순서대로 재생했다. 주 모델이 비었을 때만 보조 모델을 사용했다. 필터 끔과 일괄 제외의 프레임별 좌표·출처가 65번 기록과 같은지 대조했다.

| 시간 연결 후 지표 | 필터 끔 | 경계 일괄 제외 | 기존 궤적 안에서만 허용 |
|---|---:|---:|---:|
| 동작 중 정탐 / 270장 | 265 | 265 | 265 |
| a03 기존 복구 / 8장 | 8 | 8 | 8 |
| b06 오탐 / 94장 | 84 | 0 | 0 |
| b06 최장 연속 오탐 | 42 | 0 | 0 |
| b05 오탐 / 82장 | 0 | 0 | 0 |
| b02 77번 IoU | 0.777 | 0.000 | 0.777 |
| b02 78번 IoU | 0.697 | 0.486 | 0.697 |

조건부 필터에서 기존 동작 중 정탐 손실과 신규 복구는 모두 0장이었다. 일괄 제외와 최종 선택이 달라진 곳은 b02 77–91번 15장이었다. 77·78번의 수동 정답으로 두 장의 복구를 확인했다. 남은 13장에는 수동 정답이 없다. 필터를 끈 조건과 비교하면 b06의 84장을 제외한 모든 프레임에서 선택 박스와 출처가 같았다.

사전에 정한 기준을 통과해 다음 단일 모델·보조 모델의 처리시간 측정에서는 조건부 필터를 고정한다. b06은 규칙을 설계할 때 본 학습 배경이고 실제 화면 이탈은 b02에서 확인했다. 새 촬영 장소의 성능은 별도 검증이 필요하다.
