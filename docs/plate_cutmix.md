# 원판 증강 조건 점검과 CutMix 학습 입력 확인

1. **모션 블러**. 원판 외곽이 흐리다고 판독한 검증 3명의 4장은 입력 640에서 모두 직접 검출됐다. 여러 선수에서 흐림과 함께 미탐이 반복된 근거가 없어 재학습을 보류했다. 선명한 52장은 같은 조건에서 직접 51장, 시간 연결 후 52장을 찾았다.
2. **CutMix**. 실제 가림 영상 a03에서 2~14번의 13장 연속 미탐이 있었다. 작은 단일 사례를 대상으로 100에폭 기준 모델에서 `cutmix`만 0.0→0.30으로 바꾸는 비교를 준비했다. 45장의 학습 입력을 세 차례 처리한 사전 점검에서 135장 중 47회 시도, 12회 실제 패치 적용, 외부에서 가져온 원판 박스 14개 중 7개가 부분적으로 잘렸다. 현재 Ultralytics 구현은 기존 원판과 겹치지 않는 패치만 허용해 원래 원판과 겹친 경우는 0회였다. 부분 원판 삽입이 실제 가림에서 도움이 되는지 확인하는 조건이다. 이 사전 점검은 모델 성능을 측정하지 않는다.
3. **MixUp**. 기존 베이스라인은 이미 학습에 사용된 무원판 영상 b05·b06의 176장에서 출력이 0장이었다. 선수 제외 3-fold의 65에폭은 b06 한 배경에서 연속 오탐 8장(시간 연결 10장), 95에폭은 0/94장이었다. 다른 배경으로 바뀌어도 같은 오탐이 반복되는지를 판정할 독립 영상이 부족해 MixUp은 보류한다.

학습·검증 사람 분할과 기준 가중치를 유지한다. 학습이 완료되면 동일한 원본의 a03 2~14번과 동작 중 수동 검수 프레임 전체에서 직접 검출 및 시간 연결별 복구·손실을 비교하고, 고정 검증 사진의 mAP50–95도 함께 기록한다. [61번 실험 노트북](../notebooks/experiments/61_plate_cutmix.ipynb)
