# 원판 증강 조건 점검과 CutMix 학습 입력 확인

1. **모션 블러**. 원판 외곽이 흐리다고 판독한 검증 3명의 4장은 입력 640에서 모두 직접 검출됐다. 여러 선수에서 흐림과 함께 미탐이 반복된 근거가 없어 재학습을 보류했다. 선명한 52장은 같은 조건에서 직접 51장, 시간 연결 후 52장을 찾았다.
2. **CutMix**. 실제 가림 영상 a03에서 2~14번의 13장 연속 미탐이 있었다. 작은 단일 사례를 대상으로 100에폭 기준 모델에서 `cutmix`만 0.0→0.30으로 바꾸는 비교를 준비했다. 45장의 학습 입력을 세 차례 처리한 사전 점검에서 135장 중 47회 시도, 12회 실제 패치 적용, 외부에서 가져온 원판 박스 14개 중 7개가 부분적으로 잘렸다. 현재 Ultralytics 구현은 기존 원판과 겹치지 않는 패치만 허용해 원래 원판과 겹친 경우는 0회였다. 부분 원판 삽입이 실제 가림에서 도움이 되는지 확인하는 조건이다. 이 사전 점검은 모델 성능을 측정하지 않는다.
3. **MixUp**. 기존 베이스라인은 이미 학습에 사용된 무원판 영상 b05·b06의 176장에서 출력이 0장이었다. 선수 제외 3-fold의 65에폭은 b06 한 배경에서 연속 오탐 8장(시간 연결 10장), 95에폭은 0/94장이었다. 다른 배경으로 바뀌어도 같은 오탐이 반복되는지를 판정할 독립 영상이 부족해 MixUp은 보류한다.

학습·검증 사람 분할과 기준 가중치를 유지한다. 학습이 완료되면 동일한 원본의 a03 2~14번과 동작 중 수동 검수 프레임 전체에서 직접 검출 및 시간 연결별 복구·손실을 비교하고, 고정 검증 사진의 mAP50–95도 함께 기록한다. [61번 실험 노트북](../notebooks/experiments/61_plate_cutmix.ipynb)

## 검증 6명의 동작 중 연속 미탐 기준값

기존 100에폭 원판 모델의 저장된 예측을 수동 박스가 있는 동작 중 270장에 대조했다. 직접 검출의 미탐은 16장이었다. 시간 연결로 3장을 복구한 뒤 남은 13장은 모두 a03 2~14번에서 끊김 없이 이어졌다. 선수나 영상이 바뀌거나 중간에 채점할 수 없는 프레임이 있으면 연속 길이를 새로 센다.

같은 베이스라인을 양쪽에 넣었을 때 복구와 손실이 각각 0장인지 확인했다. 과거 200에폭 예측을 넣었을 때도 두 방법의 프레임별 판정 540개가 기존 비교표와 일치했다. CutMix 학습 후에는 같은 지표로 a03의 최장 미탐이 짧아지는지와 다른 선수에서 새로 놓친 프레임이 생기는지를 함께 본다.

## RTX 3090에서 CutMix만 바꿔 학습한 결과

기존 사람별 분할로 학습 8명의 45장과 검증 6명의 39장을 사용했다. 두 모델은 같은 Community RTX 3090에서 원본 `yolo26n.pt`로 시작했다. 입력 640, 배치 16, 시드 0, 100에폭, `patience=100`을 고정했다. 실험군의 `cutmix`는 0.30, 대조군은 0.00이다. 두 실행 모두 마지막 10에폭에는 Ultralytics가 Mosaic와 CutMix를 끈다. 두 실행의 시작부터 최종 검증과 가중치 저장까지 총 8분 56초가 걸렸다. 검증 지표로 선택된 두 `best.pt`는 Mac CPU에서 같은 설정으로 다시 채점했다.

| Mac에서 확인한 지표 | 기존 Mac 베이스라인 | 3090 대조군 | 3090 CutMix |
|---|---:|---:|---:|
| 고정 검증 39장 mAP50–95 | 0.9256 | 0.8860 | 0.8835 |
| 동작 중 270장 직접 검출 미탐 | 16 | 20 | 16 |
| 동작 중 270장 시간 연결 후 미탐 | 13 | 17 | 12 |
| a03 2–14번 시간 연결 후 미탐 | 13 | 13 | 5 |
| a03 2–14번 최장 연속 미탐 | 13 | 13 | 3 |

시간 연결을 적용한 두 3090 모델에서 CutMix가 새로 찾은 9장은 모두 a03이었다. 4·5·6·10–14번과 25번을 복구했다. 반대로 대조군이 맞혔던 a03 28번과 b02 33–35번을 잃었다. b02 34번은 두 모델 모두 박스를 냈으나 IoU가 0.521에서 0.496으로 내려가 미탐으로 집계됐다. a03 14번은 대조군에 선택된 박스가 없었고 CutMix에서는 IoU 0.87이었다. 허브를 눈으로 읽기 어려운 프레임에서는 수동 박스로만 채점했다.

기존 배포 후보인 Mac 베이스라인과 비교하면 시간 연결 후 8장을 얻고 7장을 잃었다. CutMix의 개선은 실제 가림이 있는 선수 한 명의 한 구간에서 확인했다. 배포용 원판 모델은 기존 Mac 베이스라인을 유지하고, CutMix 가중치는 서로 다른 실패를 보완할 후보로 보존한다. 같은 GPU·시드에서 한 차례 비교했으므로 새 선수에서의 재현성은 추가 검증이 필요하다.
