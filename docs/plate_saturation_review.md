# 원판 채도와 외곽·허브 오차

## 판정

원판 검출은 100에폭 베이스라인 `best.pt`와 입력 640을 유지한다. 같은 55장을 비교하면 원본의 아랫변·허브 평균 절대오차가 세 조건 중 가장 작았다. 이번에는 학습의 `hsv_s`를 바꾸지 않고 원판 PyTorch와 ONNX Runtime의 출력·지연 비교로 넘어간다.

## 실험 조건

기존 검증 6명의 무릎 통과부터 접촉까지 원본 56장을 사용했다. Mac CPU에서 가중치와 연결 이력을 고정하고 현재 장 전체의 채도만 0.5배·1.5배로 변경했다. 1.0배는 원본 픽셀이다. 후보 하한 0.001, 직접 검출 기준 0.10, 시간 연결 반경은 직전 박스 너비의 0.5배, 마지막 직접 검출 후 최대 2프레임이다. 수동 외곽 박스와 IoU 0.50 이상이면 정탐이다. 원본 56장의 선택·박스·점수는 이전 640 실행과 일치했다.

| 채도 | 직접 정탐 | 연결 정탐 | 미탐 / 56장 | 아랫변 평균 절대오차 | 허브 세로 평균 절대오차 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 원본 | 55 | 1 | 0 | 5.08 px | 5.80 px |
| 0.5배 | 55 | 0 | 1 | 5.22 px | 6.30 px |
| 1.5배 | 54 | 2 | 0 | 5.14 px | 5.93 px |

오차 두 열은 세 조건에서 모두 정탐이고 허브를 직접 판독한 **동일한 55장**의 프레임 평균이다. 미탐은 전체 56장에서 셌다. 여섯 선수의 짝비교에서 아랫변 절대오차가 줄어든 선수는 0.5배에서 2명, 1.5배에서 3명이었다.

## 대표 사례와 해석

- **b02 33번**은 원본에서 신뢰도 0.599, IoU 0.647이었다. 0.5배에서 신뢰도 0.792의 박스를 출력했지만 IoU가 0.4993으로 내려가 유일한 미탐이 됐다. 아랫변이 수동보다 약 61 px 위에 있었다. 반면 허브 세로 오차는 41.34 → 11.63 px로 줄었다. 외곽 판정과 허브 위치는 별도로 해석한다.
- **b02 35번**은 0.5배에서 시간 연결이 직접 검출로 바뀌었지만, 허브 오차는 47.94 → 51.69 px로 커졌다.
- 이번 비교는 현재 프레임의 채도에 대한 민감도를 보여준다. 실제 촬영 조명이 달라진 경우나 학습에서 채도 증강을 껐을 때의 효과는 별도 검증 대상이다. 기존 원본에서 무릎 통과→접촉 상승량을 가장 많이 작게 잡은 선수는 b02(20.20 px)였다. 여섯 선수 모두 과소측정했지만 선수별 반복 판독 변동과 코칭 해석에 미치는 영향은 추가 확인이 필요하다.

## 다음 실험

같은 원판 가중치와 같은 전처리의 입력 640으로 Mac CPU에서 PyTorch FP32와 ONNX Runtime FP32를 비교한다. Netron에서 입출력 형태를 확인하고, 두 런타임의 박스 좌표·점수와 직접 검출·시간 연결·미탐을 프레임별로 대조한다. b02 35번의 저신뢰 복구, c04 11→27번의 원판 상승량 +160.51 px를 확인하고, 같은 입력으로 예열 후 지연 중앙값과 p95를 기록한다. 허브 보정은 다음 단계에서도 여러 선수의 구간 상승량 오차가 재판독 변동을 넘는지 지켜본다.

실험은 `notebooks/experiments/44_plate_saturation_review.ipynb`에서 재현할 수 있다.
