# 원판 박스 중심을 고정한 시간 보정

## 판정

무릎 통과부터 접촉까지 원본 56장(검증 6명)에서 보정 전후 모두 56장이 정탐이었다. 평균 IoU는 0.91685에서 0.91711로 올랐지만 개별 프레임은 25장 개선·31장 하락했고 선수별 평균도 3명씩 갈렸다. 채도 0.5배인 b02 33번에서는 정탐을 복구했다. 원본에 적용할 기본 규칙으로 채택할 근거는 아직 약하다. 원판 ONNX 비교에는 기존 베이스라인 박스를 사용한다.

## 어떻게 비교했나

44번에서 선택한 박스의 중심·신뢰도·선택 출처(직접 또는 시간 연결)를 고정했다. 너비와 높이는 각각 현재 선택값과 같은 영상의 직전 원본 선택값을 1:1로 평균했다. 40번의 전체 영상 선택 표가 44번 원본과 일치하는지 확인해 구간의 첫 장에서도 실제 직전 프레임을 참조했다. 보정값은 다음 프레임에 전달하지 않았다. 수동 외곽 박스는 채점에만 사용했다.

| 현재 입력 | 정탐 전 → 후 (56장) | 평균 IoU 전 → 후 | 아랫변 평균 절대오차 전 → 후 |
| --- | --- | --- | --- |
| 원본 | 56 → 56 | 0.91685 → 0.91711 | 4.99 → 4.59 px |
| 채도 0.5배 | 55 → 56 | 0.91057 → 0.91230 | 6.22 → 5.72 px |
| 채도 1.5배 | 56 → 56 | 0.91527 → 0.91651 | 5.32 → 4.52 px |

세 조건은 같은 프레임을 재사용한다. 조건별 전체 56장에 기존 박스와 직전 박스가 모두 있었다. IoU 0.50 이상을 정탐으로 정의했다. 168개 비교 모두에서 중심의 최대 가로·세로 이동은 0 px였다. 고정된 프레임에 대한 허브 위치 오차와 상승량·속도는 보정 전후 동일하다.

## b02 33번에서 보이는 차이

채도 0.5배에서 크기가 약 268.35 × 219.64 px였던 박스를 278.05 × 237.45 px로 늘리자 IoU가 0.49934에서 0.55046으로 올랐다. 아랫변은 수동 박스보다 약 61 px 위에서 52 px 위로 가까워졌다. 같은 프레임의 원본에서는 IoU가 0.64656에서 0.62486으로 내려갔다. 원본 아랫변은 이미 수동값과 0.06 px 이내였고 보정 후 약 6.72 px 위로 이동했다. 합성 조건에서 한 번 정탐으로 바뀐 결과와 실제 원본의 측정 성능을 구분해 해석한다.
