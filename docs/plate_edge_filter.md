# 화면 경계의 납작한 원판 후보를 시간 연결 전에 제외한 결과

## 질문과 고정 조건

기존 Mac YOLO26n 베이스라인을 주 모델, 기존 3090 CutMix 모델(scale 0.50, cutmix 0.30)을 보조 모델로 사용했다. 화면 왼쪽·오른쪽·위·아래 중 한 경계까지의 거리가 원본 기준 1px 이내이고 너비가 높이의 3배 이상인 후보만 제외했다. 두 기준은 사전에 고정했다.

검증 6명의 원본 687프레임과 학습에서 본 원판 없는 b05·b06의 176프레임을 프레임 0부터 두 모델로 각각 다시 추론했다. 두 조건이 공유한 것은 추론 후보까지다. 필터를 끄거나 켠 뒤 모델별·영상별로 이력을 새로 만들고, 주 모델 출력이 비어 있을 때만 보조 모델의 출력을 사용했다. Mac CPU 입력 640, 후보 신뢰도 0.001, 직접 검출 0.10, 직전 박스 너비의 0.5배 연결 반지름, 마지막 직접 검출 후 2프레임 제한, 정탐 IoU 0.50을 유지했다. 필터를 끈 결과는 이전 실험에서 저장한 직접·시간 연결의 1,726개 선택 기록과 대조했다.

## 동작 중 정탐과 배경 오탐

| 시간 연결 후 지표 | 필터 끔 | 필터 켬 |
| --- | --- | --- |
| 수동 정답이 있는 동작 중 정탐 / 270 | 265 | 265 |
| 동작 중 미탐 / 270 | 5 | 5 |
| a03의 기존 복구 8장 중 정탐 | 8 | 8 |
| 원판 없는 b06 오탐 / 94 | 84 | 0 |
| b06 최장 연속 오탐 | 42프레임 | 0프레임 |
| 원판 없는 b05 오탐 / 82 | 0 | 0 |

동작 중에는 새로 얻거나 잃은 정탐이 각각 0장이었다. a03의 4·5·6·10·11·12·13·14번이 모두 유지됐다. b06에서는 필터를 끄면 직접 검출 75장과 시간 연결 9장이 오탐이었고, 켜면 두 종류 모두 0장이었다. b06 0번을 확대하면 주황 박스는 화면 왼쪽 위의 천장 가장자리에 걸쳐 있다.

## 실제 원판이 화면 밖으로 잘릴 때

b02 하프 동작은 마지막 수동 이벤트가 36번이다. 77·78번 원본에서 머리 위로 들어 올린 실제 원판은 위쪽이 화면 밖에 있고 아래쪽 테두리만 보인다. 기존 주 모델의 박스 너비/높이는 각각 3.57과 4.60이었다. 필터가 해당 후보를 제외하고 다른 박스를 선택했다.

| b02 프레임 | 기존 IoU | 적용 IoU | 원본에서 확인한 변화 |
| --- | --- | --- | --- |
| 77 | 0.777 | 0.000 | 화면 위 실제 원판에서 선수 오른쪽의 천장 배경으로 이동 |
| 78 | 0.697 | 0.486 | 보조 모델이 더 작은 박스를 연결해 IoU 0.50 미달 |

검증 영상에서 시간 연결 최종 출력이 바뀐 프레임은 b02 77–91번 15장뿐이었다. 77·78번은 수동 박스로 정탐 손실을 확인한 2장이다. 79–91번 13장은 수동 박스가 없어 정오 판정에서 제외했다. 사용자가 정한 동작 중 우선 지표와 이 시점 이후의 손실을 따로 기록했다.

두 모델에서 제외된 후보는 348개 프레임의 873개였다. 모델별로 Mac 701개, CutMix 172개였다. 후보 개수에는 한 프레임의 복수 박스와 최종 선택되지 않았던 박스가 포함된다. 각 후보의 원본 확대 그림을 로컬 검수 시트로 저장했다. b06의 천장, b03·b05의 바닥 경계와 b02의 실제 원판을 원본에 대조했다.

## 판단

기존 정탐을 보존하며 b06 오탐을 줄인다는 목표는 이 표본에서 달성했다. 그러나 같은 기하 조건이 화면 밖으로 나가는 실제 원판도 제거했다. b06은 기준을 정할 때 확인했던 학습 배경이다. 필터는 실험 옵션으로 보존하고 배포 기본값 적용은 보류한다. 후속 비교에서는 새 궤적을 시작할 때만 이 조건을 적용하고, 이미 이어지는 궤적에서 b02의 두 정탐을 유지하는지 볼 수 있다.
