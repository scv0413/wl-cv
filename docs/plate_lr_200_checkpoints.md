# 74. 조기 종료를 끈 원판 검출의 106·150·200에폭 비교

0.0001 선형에서 더 학습할 여지는 있었다. 106→150에폭에서 기존 정탐을 유지하고 8장을 복구해 동작 중 미탐은 43→35장, 오탐은 15→7장, 허브 상승량 평균 절대오차는 3.60→3.44px가 됐다. 그러나 좌표 누락은 43→51장으로 늘었고 a03 32–54번에서 23프레임 연속으로 끊겼다.

150→200에폭에서 전체 미탐은 35장으로 같았지만 a03에서 7장을 복구하고 b02에서 기존 정탐 7장을 잃었다. 좌표 누락은 51→22장, 최장 연속 누락은 23→12프레임으로 줄었다. 대신 오탐은 7→13장, 상승량 오차는 3.44→5.59px로 커졌다. b02의 수동 상승량은 326px였는데 200에폭 모델은 22.68px 크게 추정했다. 접촉 36번에서는 신뢰도 0.927로 밝은 안쪽 부분에 박스를 그렸고, 원판 바깥 테두리와의 IoU는 0.369였다. 같은 프레임의 기존 코사인 박스 IoU는 0.965였다.

검출 후보는 기존 0.0005 코사인을 유지한다. 세 선형 시점 중 일부 선수의 상승량은 더 정확했지만, 코사인 대조군이 동작 중 미탐 15장·오탐 0장·좌표 누락 15장·상승량 오차 2.47px로 네 지표 모두 가장 좋았다. 200에폭에서 최장 누락 12프레임은 대조군과 같았다. 이 검증셋에서는 선형 모델의 에폭을 연장하는 것만으로 대조군을 교체할 근거가 생기지 않았다.

## 학습과 채점

기존 학습 8명 45장·검증 6명 39장의 동일한 익명 입력과 원본 yolo26n.pt를 사용했다. AdamW, lr0=0.0001, cos_lr=False, epochs=200, 입력 640, 배치 16, seed=0, lrf=0.01과 증강을 유지하고 기존 저학습률 선형 실행의 patience만 30에서 0으로 바꿨다. 한 번의 실행에서 각 에폭 저장 직후 세 가중치를 복사했고 체크포인트의 내부 번호가 각각 105·149·199인지 확인했다. 200에폭 모델의 텐서와 마지막 last.pt 텐서도 일치했다. GPU에서 측정한 학습·최종 검증 시간은 132.21초였고 mAP 기준 최고 에폭은 187이었다.

새 실행은 Community NVIDIA GeForce RTX 3090, 570.211.01, 24576 MiB, 기존 코사인 대조군은 NVIDIA GeForce RTX 3090, 580.65.06, 24576 MiB에서 학습했다. 새 실행의 PyTorch는 2.8.0+cu128, Ultralytics는 8.4.202였다.

새 실행의 106에폭을 따로 확인했다. 이전 조기 종료 실행의 last.pt와도 모델 텐서가 동일했다. 두 호스트가 기록한 첫 106에폭 검증 박스 손실과 그룹 0 학습률은 같았고, GPU 검증 mAP50–95의 에폭별 절대 차이는 최대 0.00142였다.

Mac CPU에서 같은 검증 선수 6명의 원본 687프레임을 영상별로 처음부터 시간 연결했다. 수동 정답 박스가 있는 동작 중 270장에서 IoU 0.50 미만인 출력은 오탐과 미탐에 하나씩 셌고 출력이 비면 미탐으로 셌다. 좌표 누락은 동작 전체 478프레임에서 셌다. 동작 범위는 ready부터 마지막 수동 이벤트까지다. 상승량은 무릎 통과→접촉의 원판 중심 y좌표 차이로 계산했다. 평균 절대오차는 전 조건 공통으로 측정 가능한 6명에 대한 값이다.
