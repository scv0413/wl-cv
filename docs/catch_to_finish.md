# 캐치 후 일어서는 동안의 원판과 어깨 간격

검증 선수 c04의 수동 캐치(78번)와 피니시(107번) 사이 30프레임을 확인했다. Mac MPS의 단일 모델 실행에서 원판은 베이스라인, 자세는 원본 YOLO26n-pose, 두 입력은 640이었다. 30장 모두 원판이 직접 검출되고 같은 프레임에서 가까운 왼쪽 어깨와 골반이 표시됐다. 선택한 원판 박스와 화면 경계 사이의 최소 거리는 199 px였다.

## 프레임별 관찰

화면 왼쪽이 선수가 향한 앞쪽이라서 원판 박스 중심이 어깨보다 오른쪽에 있으면 뒤쪽이다. 체간은 골반에서 어깨로 향하는 선과 화면 수직선이 이루는 각도이며 0°에서 수직이다.

| 원본 프레임 | 캐치 후 경과 | 어깨 기준 원판 위치 | 체간 기울기 |
| --- | ---: | ---: | ---: |
| 78 · 캐치 | 0.00초 | 뒤 40.5 px | 32.5° |
| 92 · 가장 뒤 | 0.47초 | 뒤 82.3 px | 27.5° |
| 107 · 피니시 | 0.97초 | 뒤 34.5 px | 10.7° |

원판은 30장 내내 어깨 뒤에 있었다. 캐치에서 92번까지 뒤쪽 간격이 41.8 px 커졌다가 피니시까지 47.9 px 줄었다. 캐치와 피니시의 차이는 앞쪽으로 6.1 px였다. 체간은 중간에 등락하며 전체적으로 수직에 21.8° 가까워졌다.

좌표는 원본 픽셀 단위의 모델 출력이다. 원판 중심은 박스 중점이며, 거리는 움직이는 어깨에 대한 상대값이다. 78번에서 사람이 확인한 견봉은 가림 때문에, 골반은 소켓의 위치를 추정해 기록했다. 나머지 29장은 이 두 관절의 직접 판독이 없다. 이 관찰은 모델 측정의 예시이며 자세의 옳고 그름이나 해부학적 각도 정확도를 채점할 근거는 아직 없다.

[68번 실험 노트북](../notebooks/experiments/68_catch_to_finish.ipynb)에서 0.25배속 영상, 프레임별 곡선과 대표 3장의 원본 프레임 번호를 대조할 수 있다. 실행 결과와 선수 영상은 로컬에 저장한다.
