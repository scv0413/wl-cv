### 어느 시점에서 놓쳤나

한 칸은 수동 판독 한 장이다. ●는 최종 박스가 수동 박스와 IoU 0.50 이상인 장면, ×는 미탐이다. 풀 동작은 준비부터 피니시까지, 하프는 준비부터 바 접촉까지의 상대 시점이다.

### 원판이 보였는데도 최종 좌표가 빈 이유

하프 동작에서 무릎 통과와 바 접촉 사이의 한 프레임(54번)을 놓쳤다. 원판 모델 둘 다 수동 박스와 겹치는 후보를 냈다. 베이스라인의 신뢰도는 **0.962**, IoU는 **0.933**이었고 CutMix는 각각 **0.951**, **0.935**였다. FiftyOne으로 앞뒤 프레임을 대조하니 자세 모델이 같은 수행자에게 상체·전신 범위의 사람 박스를 세 개 그렸다. 직전 수행자와 가장 잘 겹친 상체 박스는 전신 박스 면적의 31%여서 기존 수행자 선택 조건을 통과하지 못했다. 수행자를 결정하기 어려울 때 적용하는 원판 필터에서도 탈락해 최종 좌표가 비었다. 53번과 55번은 직접 검출이었다. [필터 전후 원판 후보](results/plate_holdout/a07_frame54_diagnostic.csv) · [세 프레임의 사람 박스](results/plate_holdout/a07_people_53_55.csv)

**후속 실험에서 내린 결정.** 상체 박스를 전신 박스에 포함해 판단하면 이 한 장은 복구됐다. 기존 검증 6명의 수동 박스 270장에서는 두 방식 모두 미탐 5장·오탐 0장으로 같아 배포 규칙을 유지했다. [조건과 프레임별 대조](plate_person_containment.md)

### 분할과 해석 범위

- 전체 분할표에 배정된 영상은 학습 31편·검증 16편·테스트 7편이다. 실제 첫 학습에 쓰인 원판 라벨은 8명·45장, 모델 선택용 검증 라벨은 6명·39장이다. 테스트 3명의 모든 시도를 함께 분리했다. 과거에 원판 없는 영상을 찾으며 일부 장면을 육안으로 본 이력이 있어 기존 자료에서 분리한 후향 테스트로 기록했다. [선수별 분할표](../data/splits/person_split.csv) · [테스트 원본 목록과 해시](../data/splits/plate_holdout_videos.csv)
- [블라인드 판독 노트북](../notebooks/annotation/20_plate_holdout.ipynb)에서 각 동작의 다섯 시점을 지정하고 원판 박스를 저장했다. 35장 모두 원판이 있었으므로 빈 화면에서의 오탐률은 미측정이다. 반복 시도가 포함된 세 선수의 결과이며, 새로운 촬영 환경에서의 성능도 별도 검증이 필요하다.
- 입력 640, 베이스라인과 CutMix 자동 보완, 기존 수행자 선택과 시간 연결로 영상 첫 프레임부터 처리했다. 7편 전체 605프레임 중 604프레임에서 좌표가 나왔다. 좌표 유무는 모든 프레임에서 확인할 수 있지만, 박스의 정확도는 정답이 있는 35장에서만 채점했다. 허브 위치·순간 속도는 이 표로 평가하지 않았다.
