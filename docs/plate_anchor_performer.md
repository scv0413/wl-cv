# 보류된 수행자를 원판 중심으로 다시 고른 결과

원판이 직접 검출되고 기존 수행자 선택이 보류된 프레임에서만 원판 중심을 포함한 사람 박스를 찾았다. 정확히 하나일 때 그 박스의 가까운 무릎을 확인했다. 보완한 선택을 다음 프레임의 이력에는 쓰지 않았다. 입력 크기, 원판 좌표, 무릎 신뢰도와 기존 선택은 고정했다.

| 선수 | 기존 동시 관측 | 보완 후 | 보완 후에도 비어 있는 원본 프레임 |
|---|---:|---:|---|
| a01 | 0/12 | 5/12 | 8~14 |
| a06 | 7/12 | 12/12 | 없음 |
| a08 | 0/11 | 4/11 | 18~24 |
| b00 | 0/11 | 11/11 | 없음 |
| b01 | 10/11 | 11/11 | 없음 |
| b04 | 13/13 | 13/13 | 없음 |
| c02 | 10/12 | 12/12 | 없음 |

두 수동 판독에 전후 5장을 더한 창에서 동시 관측이 40/82장에서 68/82장으로 늘고 창 전체가 이어진 선수는 1명에서 5명이 됐다. 새로 붙은 28장의 오버레이를 확인했을 때 배경 인물을 선택한 뚜렷한 사례는 보이지 않았다. 이 28장에는 독립 수동 전신 박스가 없었다. 범위를 ready~drive 180장으로 넓히면 새 선택 48장 중 a08 29번에 수동 박스가 있어 IoU 0.826을 확인했다. 이는 무릎의 해부학적 위치 검증과는 별개의 결과다.

## 같은 TCN 재비교

정답으로 자른 창을 입력에 사용하지 않고 60번과 같은 수동 ready~drive 전체에서 추론했다. 기존 선수 제외·모델·시드·입력 정규화·학습 설정을 고정했다. 높이 규칙은 판정 가능 선수가 4명에서 6명으로 늘었다. 처음부터 판정 가능했던 4명의 평균 절대 수동 범위 이탈 시간은 64.6 ms로 같았다. 보완 뒤 두 방법이 모두 출력한 같은 6명에서 규칙은 **79.2 ms**, TCN(seed 0)은 **390.6 ms**였다. TCN은 7명 모두에 출력했으며 7명 전체에서 seed 0·1·2의 평균은 각각 334.8·346.7·159.5 ms였다. a08의 수동 23번에는 두 좌표가 없었고 TCN은 주변 프레임으로 후보를 냈다. b04에서 양끝인 ready 5번이 선택되는 등 경계 오차가 컸다.

추가 관측은 후보 검토에 활용하되, TCN을 코칭용 자동 시점으로 채택하지 않는다. 새 선수와 여러 배경에서 독립 수행자 박스로 오연결을 확인하는 일이 남았다.
